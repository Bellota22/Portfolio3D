Política de Privacidad

Última actualización: 2026-10-20

1. Datos que se recopilan

Este sitio no recopila datos personales de forma intencional, salvo lo que envíes voluntariamente en el formulario de contacto (si aplica).

2. Cookies / analítica

Si se usa analítica (por ejemplo, Google Analytics), podría recopilar datos técnicos (navegador, páginas visitadas). Puedes desactivar cookies en tu navegador.

3. Enlaces a terceros

Este sitio puede incluir enlaces a servicios externos (GitHub, LinkedIn, etc.). Sus políticas aplican al salir de este sitio.

4. Contacto

Para consultas sobre privacidad, contáctame mediante los canales del portafolio.

5. Uso de la API de YouTube (canal propio)

El pipeline de automatización de este sitio opera exclusivamente sobre el canal de YouTube del propio dueño del sitio (@bellotacuriosidades): sube sus propios videos, lee las analíticas de su propio canal y gestiona los comentarios de sus propios videos mediante la YouTube Data API v3. No se recopilan, almacenan ni comparten datos de usuarios de terceros.

El uso de la API de YouTube Data está sujeto a las Políticas para Desarrolladores de YouTube API Services, y puedes consultar la Política de Privacidad de Google en cualquier momento.

6. Eliminación de datos

Este sitio no almacena datos personales de usuarios. Para eliminar contenido publicado en tu propio canal de YouTube, usa YouTube Studio. Para revocar el acceso de aplicaciones a tu cuenta de Google, entra en la página de permisos de tu cuenta de Google. Si querés que eliminemos algún dato asociado a este sitio, escribinos por los canales de contacto.
